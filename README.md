## The joke

> My coin found strong support at zero. It has held beautifully ever since.

"Finding strong support" sounds like good news — until the support turns out to be at zero, and the kicker praises how beautifully zero has held. A TA-vocabulary joke with the punchline at the very end.

## How it works

`main.ts` writes the joke above to `/output/entry.txt` — one line, 73 characters — after checking it against the competition gate (1–200 characters, not only whitespace, exactly one line, no leading or trailing whitespace, no control characters).

Run it with Node 22 or later:

```sh
node main.ts
```
